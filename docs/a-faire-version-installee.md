# À faire avec une version installée de l'app

Ces points demandent une version installée de l'app (build de développement ou version publiée), pas Expo Go.

- Passer à un moteur audio léger (par exemple react-native-audio-api) pour remettre un tick à chaque cran des curseurs et réduire la latence des sons, et utiliser un générateur de vibration gardé prêt. Demande une version installée de l'app, pas Expo Go.
